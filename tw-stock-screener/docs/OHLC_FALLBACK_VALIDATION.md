# 官方 OHLC 補缺實作與驗證

日期：2026-10-11（Asia/Taipei）。確認需求見SPEC第15節：其他官方資料仍找不到有效同日價格，就保留缺值。

## 本機實作

| 項目 | 行為 |
| --- | --- |
| 來源 | 沿用TWSE MI_INDEX及TPEx dailyQuotes，全市場官方日報；不接入FinMind或其他非官方來源。 |
| 使用時機 | 個股必要歷史列有缺價格，才按需讀取同一市場、股票、日期的日報；已快取資料先重用。 |
| 有效補缺 | 四欄均為有限正數，開收在高低之內，且與原列已存在的正值一致，才使用完整OHLC。 |
| 無法補缺 | 備援缺價／零價、來源失敗、沒有同股票同日資料或價格衝突，保留原值與未解原因；不跳過缺日或降低暖機。 |
| 保留 | 原月資料不改寫；來源日報保存於每日快取，原始回應仍由來源模組保存。 |
| 不影響 | 原始排名行情、精確成交股數、量比、KD公式、窗口、普通股範圍、前300及未完成棒政策。 |
| 可追溯 | JSON的data_quality含原OHLC、替代OHLC、來源URL、日報列SHA-256與狀態。規則雜湊包含補缺政策，輸入雜湊包含補缺紀錄。 |

主要程式為`price_fallback.py`；一般DemandHistory及managed的CheckedDemandHistory共用。`application`保存補缺資訊，純計算核心不依賴來源或儲存。設定`data_quality.ohlc_fallback: official_daily`預設開啟；`none`供舊政策的回歸比較。

同一供應器對同一市場／日期只使用一份日報；補缺仍失敗時停止該階段其餘補缺查詢，避免為已確定無法通過的歷史多抓資料。API重試沿用既有有限預算。必要本機存檔失敗仍停止，不當作一般缺值吞掉。

## 限制與狀態

補缺機制完成不代表155檔資料不足已修復。四個實測日期目前仍缺價格；本次沒有重新下載未快取的其他日期，也不能推論所有其他日期都補不回。新增完整重算會產生待確認版本，不能自動取代正式版。

外部看盤軟體KD比對仍待驗收。本次只更新本機程式、設定、測試與文件，沒有GitHub提交、Pages部署、每日排程或結果approve。
